# Thread Mover Bot Privacy Policy

Last updated: September 21, 2026

Thread Mover Bot processes Discord messages only when a user invokes the
`/move` command. To perform that command, the bot accesses recent messages in
the current channel, including their text, author information, timestamps,
embeds, and attachments. It reposts that information into the requested
Discord thread and then attempts to delete the original messages.

The bot does not maintain a database or use message data for advertising,
profiling, analytics, or sale. Message data and attachments are processed only
for the duration of the command. Reposted messages remain stored by Discord
until they are deleted through Discord. Basic operational error logs may be
retained by the bot's hosting provider and may include message IDs, display
names, attachment filenames, or Discord API error details.

Information processed by the bot is sent only to Discord as necessary to
provide the message-moving functionality. Discord's own handling of data is
governed by the [Discord Privacy Policy](https://discord.com/privacy).

Server administrators control where the bot can operate through Discord
permissions. Users may ask a server administrator to delete reposted content.
For privacy questions or requests concerning Thread Mover Bot, contact
[sojscoder@gmail.com](mailto:sojscoder@gmail.com).

This policy may be updated when the bot's functionality or data practices
change. Material changes will be reflected by updating the date above.
